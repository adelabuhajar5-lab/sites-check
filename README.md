
- `lib/xlsx_reader.dart` - reads the `data` tab straight from the .xlsx
- `lib/site_book.dart`   - FIELDS list, norm()/fmt() rules, filtering (port of the Python logic)
- `lib/search_box.dart`  - type-ahead box
- `lib/main.dart`        - responsive screen (1 column on phones, 2 on tablets)
